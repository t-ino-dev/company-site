# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ株式会社」の企業サイト(サンプル)です。HTMLとCSSのみで作られた1ページ完結のシングルページサイトで、ビルドや外部ライブラリは不要です。

> ※ 本サイトに登場する企業名・人物名・住所・メールアドレスはすべて架空のものです。

## サイトの概要

Webアプリ、モバイル、クラウド基盤などの受託開発とプロダクト開発を行う企業、というコンセプトのサイトです。ページ内には次のセクションがあります。

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピーと問い合わせ・事業内容への導線 |
| 実績数値 | プロジェクト数、従業員数、継続率、創業年 |
| 事業内容 | Web開発、モバイル開発、クラウド構築、AI・データ活用、UI/UXデザイン、保守・運用支援 |
| 開発実績 | 配送最適化システムなど3件の事例 |
| 会社情報 | 価値観と会社概要 |
| お知らせ | 最新ニュース一覧 |
| お問い合わせ | メールでの問い合わせ窓口 |

### 特徴

- レスポンシブ対応(幅820px以下でスマートフォン向けレイアウトに切り替え)
- ダークテーマのデザイン
- ヘッダーのメニューからセクションへスムーズスクロール
- `prefers-reduced-motion` に対応(アニメーションを控えたい設定を尊重)

## ブラウザでindex.htmlを開く手順

サーバーやインストールは不要で、ファイルをブラウザで開くだけで表示できます。

### 方法1: ダブルクリックで開く

1. このリポジトリをクローン、またはダウンロードして任意のフォルダに配置します。
2. エクスプローラー(Finder)で `index.html` を探します。
3. `index.html` をダブルクリックします。既定のブラウザで開きます。

### 方法2: ブラウザにドラッグ&ドロップする

1. ChromeやEdge、Firefox、Safariなどのブラウザを起動します。
2. `index.html` をブラウザのウィンドウへドラッグ&ドロップします。

### 方法3: ブラウザのメニューから開く

1. ブラウザを起動します。
2. `Ctrl + O`(Macでは `Cmd + O`)を押してファイル選択ダイアログを開きます。
3. `index.html` を選んで開きます。

### 方法4: コマンドラインから開く

リポジトリのフォルダで次のコマンドを実行します。

```bash
# Windows (PowerShell / コマンドプロンプト)
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

## ファイル構成

```
company-site/

```

## 編集するには

`index.html` をテキストエディタで編集し、保存後にブラウザを再読み込み(`F5`)すると変更が反映されます。スタイルは `<head>` 内の `<style>` に、配色は冒頭の CSS 変数(`:root`)にまとまっています。
